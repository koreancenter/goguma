## 섹션 1: [Level 1] 무설치 브라우저 모드 (Zero-Setup)

> **소요 시간**: 10초
> **준비물**: 크롬(Chrome), 엣지(Edge), 또는 웨일(Whale) 최신 브라우저

1. **브라우저 실행 및 접속**:
* 크롬이나 엣지 브라우저를 엽니다. (사파리는 WebGPU 설정이 복잡하므로 크롬 계열을 권장합니다.)


2. **첫 AI 체험 (WebLLM 자동 캐싱)**:
* 고구마 앱에서 [AI로 1줄 다듬기] 또는 [가이드 요청] 버튼을 누르면, 화면에 *"로컬 인공지능 붓을 준비하는 중입니다..."* 안내가 뜹니다.
* 최초 1회만 약 300MB(스마트폰 사진 몇 장 분량)의 초소형 인공지능 모델이 다운로드되며, 2~3초 후 즉시 사용 가능합니다.


3. **오프라인 동작 확인**:
* 한 번 다운로드된 모델은 내 컴퓨터 브라우저 안(`CacheStorage`)에 영구 보관됩니다. 인터넷 연결을 끊어도 AI 가이드가 정상 작동합니다.

## 섹션 2: [Level 2] 내 컴퓨터 로컬 AI (Ollama) 연결하기

> **소요 시간**: 약 5분
> **대상**: 데이터가 외부로 나가는 것이 싫고, 더 똑똑한 오픈소스 모델(`qwen2.5-coder`, `gemma2` 등)을 무료로 무제한 쓰고 싶은 분

### Step 1. Ollama 프로그램 설치

1. [ollama.com](https://ollama.com?utm_source=gemini)에 접속하여 본인의 운영체제(Mac 또는 Windows)에 맞는 설치 파일을 다운로드하고 실행합니다.
2. 설치가 끝나면 화면 우측 하단(윈도우) 또는 상단 메뉴바(맥)에 라마(Llama) 모양의 귀여운 아이콘이 생깁니다.

### Step 2. 추천 모델 딱 1개 다운로드

1. 컴퓨터에서 **[터미널]**(Mac) 또는 **[명령 프롬프트/PowerShell]**(Windows)을 켭니다.
2. 아래 명령어를 그대로 복사해서 붙여넣고 `Enter`를 칩니다:
```bash
ollama run qwen2.5-coder:7b

```

*(※ 코딩과 명세 작성에 가장 뛰어난 모델이며, 약 4GB의 파일이 다운로드됩니다.)*
3. 다운로드가 끝나고 터미널에 `>>>` 표시가 뜨면 설치가 끝난 것입니다. 터미널 창을 닫아도 됩니다.

### Step 3. 고구마 앱과 안전하게 연결하기 (가장 중요! ★)

브라우저는 보안상 로컬 컴퓨터(`11434` 포트)에 접근하는 것을 기본적으로 차단합니다. 이를 열어주기 위해 딱 한 번만 아래 명령어로 Ollama를 켜주어야 합니다.

* **Windows 사용자 (PowerShell에서 실행)**:
```powershell
$env:OLLAMA_ORIGINS="https://goguma.app,https://*.goguma.app,http://localhost:*"
ollama serve

```


* **Mac 사용자 (터미널에서 실행)**:
```bash
OLLAMA_ORIGINS="https://goguma.app,https://*.goguma.app,http://localhost:*" ollama serve

```


* 고구마 앱 상단에서 `● Ollama 연결됨 (qwen2.5-coder:7b)` 초록색 불이 들어오면 모든 준비가 끝납니다.

## 섹션 3: 자주 겪는 문제와 10초 해결법 (Troubleshooting)

### Q1. "브라우저에서 WebLLM 로딩이 멈추거나 실패했다고 떠요."

* **원인**: 브라우저의 WebGPU(그래픽 가속) 기능이 꺼져 있는 경우입니다.
* **해결법**:
1. 크롬 주소창에 `chrome://settings/system` 을 입력하고 이동합니다.
2. **[가능한 경우 그래픽 가속 사용]** 토글이 켜져 있는지 확인하고 브라우저를 재실행합니다.



### Q2. "Ollama를 켰는데 고구마 앱에서 '연결 실패'라고 나와요."

* **원인**: 위의 Step 3(CORS 허용) 설정 없이 기본 방식으로 Ollama가 켜져서 브라우저가 통신을 막은 것입니다.
* **해결법**:
1. 작업 표시줄(윈도우)이나 상단바(맥)에서 실행 중인 라마 아이콘을 마우스 우클릭하고 [Quit Ollama]로 완전히 끕니다.
2. 위의 **Step 3 명령어**를 복사해서 터미널에 붙여넣고 다시 엽니다.



### Q3. "코딩 에이전트(Cursor, Claude Code)에 이 문서를 어떻게 주나요?"

* **해결법**:
1. 고구마 앱 우측 상단의 **[프로젝트 내보내기]** 버튼을 눌러 `goguma-blueprint.zip`을 다운로드합니다.
2. 압축을 풀면 나오는 폴더 전체를 Cursor 프로그램 위로 그냥 드래그 앤 드롭해서 열어주기만 하면 됩니다.
